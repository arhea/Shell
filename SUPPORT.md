# Getting help

Shell is a volunteer-maintained open-source project. There's no paid support, but here's the fastest way to an answer.

| You want to… | Go to |
| --- | --- |
| Learn how to use Shell | [Getting started](docs/getting-started.md) and the [docs](docs/README.md) |
| Fix something that isn't working | [Troubleshooting and FAQ](docs/troubleshooting.md) |
| Report a bug | [Open a bug report](../../issues/new/choose) |
| Suggest a feature | [Open a feature request](../../issues/new/choose) |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md). Don't open a public issue. |
| Contribute a fix | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you open an issue

1. Search [existing issues](../../issues?q=is%3Aissue), including closed ones.
2. Update to the latest release. The bug may already be fixed.
3. Collect a diagnostic snapshot (see [Troubleshooting › Collecting diagnostics](docs/troubleshooting.md#collecting-diagnostics)), and check it for secrets before attaching it.

## Problems with other tools

Shell drives tools it doesn't own. Report problems with the tool itself upstream:

| Tool | Where |
| --- | --- |
| Terminal emulation, rendering, fonts (libghostty) | [Ghostty](https://github.com/ghostty-org/ghostty) |
| Claude Code | [anthropics/claude-code](https://github.com/anthropics/claude-code/issues) |
| Codex | [openai/codex](https://github.com/openai/codex/issues) |
| GitHub CLI | [cli/cli](https://github.com/cli/cli/issues) |
| Homebrew | [Homebrew/brew](https://github.com/Homebrew/brew/issues) |

If you're not sure whether a problem is Shell's, open an issue here and we'll help work it out.
